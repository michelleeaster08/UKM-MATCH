UKM MATCH - Proyek Praktikum HTML5

Isi:
- index.html: halaman beranda
- ukm.html: daftar contoh UKM
- pendaftaran.html: persyaratan, tabel jadwal simulasi, dan formulir
- images/: ilustrasi SVG untuk website

Cara membuka:
1. Ekstrak folder UKM-MATCH.
2. Buka folder UKM-MATCH.
3. Klik dua kali index.html untuk membuka website di browser.

Catatan:
Nama UKM, jadwal, dan lokasi merupakan data simulasi untuk praktikum, bukan informasi resmi ITPLN.
Formulir hanya demonstrasi HTML dan belum mengirim atau menyimpan data.
